- (decision) PRD scope REFINED vs brief v1: Phase 1 = shop-owner posting tool ONLY (photo->AI listing->edit->publish to locos data + auto-post to Facebook). ALL shopper-facing search deferred to Phase 2 (brief had lightweight search in v1). Products still stored/listed in locos so Phase 2 search has data. Working mode: Fast path.
- (decision) Auth: accounts manually provisioned by locos team (NO self-service signup). Login = phone number + OTP via SMS (enter phone -> receive OTP -> enter OTP -> session).
- (decision) Facebook: shop connects one Page by logging into FB + authorizing; app exchanges for a Page access token, stored, one-time. Phase 1 channel = Facebook only (other channels e.g. Zalo/IG/TikTok deferred).
- (decision) AI generation: input = few product photos + rough description (optional price); output = Vietnamese title/description/price + model-wearing images. Image must show the ACTUAL product but perfect fidelity is NOT a Phase-1 gate (AI quality will improve). Shop owner can pick model attributes (gender, style). Unlimited regenerations in Phase 1 (no cap yet). Owner can edit title/desc/price before publish.
- (decision) Localization: Vietnamese UI + Vietnamese generated content. Device: responsive web (desktop + mobile). Catalog: shop can view/edit/delete products + mark sold out. Scale assumption: grow to thousands of shops, each posting new product daily.
- (decision) Publishing: on publish, product saved to locos catalog (shop-scoped) AND posted to connected FB Page. FB post self-contained (images + Vietnamese caption + price + shop contact). NO watermark/discovery link in Phase 1 (Phase 2).
- (event) Fast-path full PRD draft written: Overview, Goals+Metrics (w/ counter-metrics), Users+UJ-1, Scope, 23 FRs (auth/FB/AI-gen/publish/catalog), 7 NFRs, Dependencies, 6 Open Questions. Inferences tagged [ASSUMPTION].
- (decision) OQ1 resolved: locos NEVER edits/deletes an existing Facebook post. Posting to FB is a distinct 'Post/Republish to Facebook' action, ALWAYS available on any product regardless of whether it was posted before; each republish creates a NEW FB post with current content. Editing a product updates only the locos catalog record; owner reflects edits on FB by republishing. Decouples catalog-save from FB-post.
