- (decision) Working mode: Fast path. Same mode as brief + PRD. Visual identity: clean neutral default. Why: matches tool-first posture and avoids competing with shop's own content in product photos.
- (decision) [OQ2 RESOLVED] Model attributes = Gender (female/male) + Style preset dropdown (small set, names TBD e.g. Casual / Chic / Streetwear). No body type / background / age / vibe for Phase 1. Why: cheapest path that still gives meaningful variation; aligns with low UX-bar owners.
- (decision) Regeneration UX: each product can have several generated images. Regenerate button is per-image (re-rolls that image only). Owner can delete any generated image they don't like. Text is never re-rolled — owner edits inline. Why: minimizes AI spend, keeps owner's edits intact, mirrors UJ-1.
- (decision) Generation wait UX: single-screen placeholder (skeleton + short copy) → same screen reveals result. Why: keeps owner in flow, lowers 'is it broken?' anxiety.
- (decision) Catalog default view = grid (image-forward, sold-out badge). Why: matches owner mental model of inventory, scans well on mobile.
