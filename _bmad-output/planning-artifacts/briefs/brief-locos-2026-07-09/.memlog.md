- (decision) Product: locos — two-sided web platform. Fashion shop owners post products; shoppers search/discover products near them by area. Core value = local discovery.
- (decision) Non-transactional: locos shows shop phone+address; shopper contacts/visits shop directly. No on-platform payments (discovery/lead-gen, not marketplace).
- (decision) First market: Ho Chi Minh City, Vietnam.
- (decision) Supply-side wedge (cold-start solution): shop owner's hook is an AI tool — generates AI image of model wearing product + marketing text, then auto-posts to their Facebook fanpage. Post once, appears everywhere (FB + locos listing). Tool has standalone value with zero shoppers.
- (decision) Demand loop: AI image carries locos.vn watermark; FB post includes link + 'open locos.vn to discover more around you'. Every shop's own FB marketing becomes distribution/acquisition for locos. Shoppers meet locos inside Facebook.
- (decision) STRATEGIC FRAME / stakes: Team already runs a B2B business supplying these fashion shops. locos = value-add customer-success tool for existing customers, NOT a standalone venture. Primary goal: help shop owners succeed + strengthen supplier relationship. locos marketplace success = upside optionality. Existing customer base = supply-seeding channel (unfair advantage). Right-size brief accordingly — lean, honest, not investor-grade.
- (decision) Shop owner flow: takes few product photos + writes description (optional price) -> AI generates final title/description/price + model-wearing images -> owner can edit + regenerate -> publishes to locos. Auto-post to FB/other channels uses a basic 'default profile' (per-channel customization = later phase).
- (decision) FB post is SELF-CONTAINED: has all info shopper needs (product + shop contact) — no need to hop to locos to buy/contact. locos link only drives 'discover more products around you'. locos watermark on images.
- (decision) Shopper flow on locos: share location + text search -> locos returns matching products from all shops within configurable max distance. Location-aware text search over local inventory.
- (decision) locos is FREE to everyone; no monetization plan for now (accepted cost of retention play).
- (decision) Success: primary signal = shop posting frequency / active shops using tool (supply retention). Honest unknown = attribution of buyer-lift to shops (can't measure yet). Deliberate sequencing: Phase 1 win supply cheaply via tool; Phase 2 (later) invest in expensive buyer acquisition. Shop profile: variety of small/independent shops, NOT big chains/giants.
